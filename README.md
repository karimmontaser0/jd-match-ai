# 🎯 JD-Match: AI Mock Interviewer

> An intelligent, multi-turn AI mock interviewer powered by RAG and Google Gemini, designed to simulate software engineering interviews based on specific job descriptions.

## ✨ Key Features
* **Context-Aware Questioning:** Utilizes a RAG pipeline with vector embeddings and semantic search to retrieve job-description context for accurate multi-turn interview simulations.
* **Dynamic Analysis:** Integrates advanced LLMs to dynamically analyze and score user responses.
* **Comprehensive Evaluation:** Evaluates candidates against 50+ contextual criteria specific to the job description.
* **Real-time Feedback:** Provides actionable, real-time feedback to help candidates improve.

## 🛠️ Tech Stack
* **Language:** Python
* **AI & NLP:** Google Gemini API, LangChain, Prompt Engineering
* **Architecture:** Retrieval-Augmented Generation (RAG)
